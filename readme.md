
# Prompt Quizzer - A Quiz Game

## Web Dev I - Lab Assignment 4

### Description
Prompt Quizzer is a simple JavaScript-based quiz game
that runs entirely in the browser console.

It asks predefined questions, accepts user answers,
checks their correctness, and displays the final score.

### Features
- 10 predefined quiz questions
- User input using prompt()
- Answer checking using if-else
- Case-insensitive answer comparison
- Extra whitespace handling using trim()
- Immediate feedback using alert()
- Score tracking
- Final score display

### Technologies Used
- JavaScript
- Google Chrome Developer Tools

### JavaScript Concepts Used
- Arrays
- Objects
- Functions
- For loops
- If-else statements
- Variables
- String methods

### How to Run
1. Open Google Chrome.
2. Open Developer Tools using Ctrl + Shift + J.
3. Select the Console tab.
4. Copy the code from quiz.js.
5. Paste the code into the console.
6. Press Enter.
7. Answer all the quiz questions.
